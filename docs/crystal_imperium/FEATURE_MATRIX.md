# Crystal Imperium: feature compatibility matrix

Status values:
- **Done**: implemented in this repository and verified (the evidence column says how).
- **Existing**: already in Heart & Soul 2.0.6. Unchanged unless noted.
- **Missing**: not implemented yet.
- **Blocked**: cannot be done as specified. The reason and the alternative are given.
- **Unverified**: present in the code but not yet tested by us.

Evidence key: *emu* = emulator play test in `tools/emurun/tests/` (screenshots plus memory
assertions); *build* = compiles into the ROM; *val* = `tools/crystal_imperium/validate.py`.

| Feature | Status | Evidence / notes |
|---|---|---|
| Johto story (New Bark → Lance), rival, Rockets, beasts, Kimono Girls, Ho-Oh/Lugia | Existing / Unverified | HnS content. Only boot → New Game → bedroom has been played through so far. |

| Whiteout after a lost battle | Done | emu: Falkner loss line returns the player home. |

## Minimal Grinding (Section 8)

| Feature | Status | Evidence / notes |
|---|---|---|
| Minimal Grinding Mode option (default ON) | Done | emu: the menu shows it ON. Lv 11 Cyndaquil has 32 max HP, which is exactly 31 IV / 0 EV. |
| Standard IVs / no EVs for all Pokémon | Done | emu (player side). Trainer side is the same code path. |
| Level caps tied to progression | Existing, defaulted ON | emu: "gained 0 EXP" at the cap during the Falkner fight. |
| Practical EXP gain | Existing, defaulted ×1.5 | HnS option. The New Bark lab script can enable the party-wide EXP Share (`FLAG_EXP_SHARE_ENABLED`); when that happens is not yet verified. |
| Nature changes (Mints) | Existing | Goldenrod Flower Shop after the 3rd badge. |
| Ability Capsule / Patch access | Done | emu: `flower_shop`. Now sold beside the Mints (₽20k / ₽40k). |
| Move relearner | Existing / Unverified | HnS Blackthorn house. Imperium has a menu relearner, which is missing here. |
| Reusable TMs | Existing | HnS option (default ON). |
| Trade evolutions without trading | Unverified | Needs an audit of evolution methods. Not done. |
| No mandatory breeding | Existing | No required breeding in HnS. |
| EV/IV editor (Imperium item) | Missing | Mostly unnecessary while the mode is ON. Low priority. |

## Pokémon availability (Section 7)

| Feature | Status | Evidence / notes |
|---|---|---|
| Gen 1–9 species data, Fairy type, Hidden Abilities | Existing | All `P_GEN_*_POKEMON TRUE`. Fairy type is an option (default ON). |

## Battle mechanics (Section 9)

| Feature | Status | Evidence / notes |
|---|---|---|
| Physical/special split, modern moves/abilities/crits/weather | Existing | RHH engine. Split is an option (default ON). |
| Mega Evolution (48 classic stone Megas + Rayquaza) | Done | emu: `mega_evolution` (player Ampharos → Mega with R in the move menu; Lance's Gyarados Mega Evolves on turn 1) and `mega_specialist` (Mega Ring gift, tiered stone shop). ROM 94.5% → 98.75%. The 48 Z-A Megas stay off: they would add another 0.44% (≈145 KB) of ROM. |
| Primal Reversion | Missing | Same budget concern. Groudon/Kyogre are not part of the main HnS story. |
| Emerald Imperium's 24 custom Megas (Butterfree, Empoleon D/O, Infernape, Luxray, Machamp, Snorlax, Torterra, Lapras, Kingler, Gigantamax conversions, …) | **Blocked** | No license or permission to reuse their sprites and data (D2). They also need ROM space. Alternative: original designs, or ask the Imperium team for permission. |
| Mega trigger button | Done | HnS maps START to move info, so the Mega trigger could never fire. It is now on R (`B_GIMMICK_TRIGGER_BUTTON`). |
| Tera / Dynamax / Z-Moves | Existing in the engine, unused | Not part of the Crystal Imperium design. |

| Feature | Status | Evidence / notes |
|---|---|---|
| Valid GBA ROM (header fixed by gbafix, 32 MB) | Done | build. |
